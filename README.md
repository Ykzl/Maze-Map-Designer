# 迷宫地图编辑器 · Maze Map Designer

一个用 Python + Tkinter + Pillow 写的**多层平面迷宫地图编辑器**。只做「编辑与显示」，不做游玩、不做自动生成、不做寻路。

![1 层](preview_f1.png)

## 1. 需求对照

| 需求 | 实现 |
| --- | --- |
| 平面迷宫，正方形单元，薄墙 | 墙位于两个相邻单元的交界处，由**两个方向**独立描述 |
| 多层 | 楼层栈，可增删、上下移动、逐层编辑 |
| 设置迷宫大小 | 工具栏「宽 / 高 / 应用尺寸」；层数可设 |
| 保存并读取文件 | JSON 文件（`Maze.save` / `Maze.load`，工具栏「打开 / 保存 / 另存为」） |
| 鼠标编辑 | 左键绘制、右键擦除/循环、中键拖动平移、Ctrl+滚轮缩放 |
| 连通状况三种 | ① 连通且不绘制 ② 不连通 → 实线 ③ 单向连通 → 虚线 + 箭头 |
| 单元种类四种 | ① 空气（透明）② 普通地面（白底）③ 单向传送门（白底 + 指向目的地中心的箭头，仅同层）④ 文本单元（白底 + 居中自适应文本） |
| 楼层颜色从配置文件读取 | `config.json` 的 `color_group`，默认 黑/红/橙/黄/绿/青/蓝/紫，循环使用 |
| 传送门箭头颜色单独配置 | `config.json` 的 `portal_color`，默认 `#FF00FF` |
| 透明度按距离衰减 | 当前层 0%，上下 1 层 50%，2 层 75%，3 层 87.5%…（`0.5^距离`） |
| 绘制顺序自下而上 | 按楼层栈从底到顶合成，高层自然覆盖低层 |

## 2. 运行

需要 Python 3.9+（开发环境 3.11.3）。依赖只有 Pillow：

```powershell
pip install pillow
python app.py                 # 打开示例迷宫开始编辑
python app.py my_maze.json    # 打开已有迷宫文件
```

`config.json` 不存在时会自动写入默认配置。

### 生成 preview 图片（不开窗口）

```powershell
# 示例迷宫，1 层为当前层，棋盘底显示透明区域
python cli.py --sample --out preview_f1.png --checkerboard --cell-size 56 --active 0

# 只画墙和单向箭头（不画任何单元内容），用于核对墙的位置
python cli.py --sample --out preview_walls_f1.png --cell-size 56 --active 0 --walls-only

# 渲染自己的迷宫文件，并另存一份 JSON
python cli.py my_maze.json --out my.png --cell-size 40 --active 1 --save-json copy.json
```

常用参数：`--out` 输出 PNG、`--active` 当前编辑楼层的**栈内下标**（0 = 最底层）、
`--cell-size` 单元格像素、`--checkerboard` 棋盘底、`--walls-only` 只画墙、
`--config` 指定配置文件、`--save-json` 顺手另存迷宫。

### 测试

```powershell
python tests\test_maze.py    # 数据模型 / 配置 / 渲染的像素级检查（34 项）
python tests\test_gui.py     # GUI 冒烟测试：模拟鼠标编辑、存读、缩放
```

## 3. 怎么编辑

### 3.1 界面分区

* **第一行**：文件（新建 / 打开 / 保存 / 另存为）、迷宫宽高、层数（应用层数 / ＋层 / －层 / 删除层）。
* **第二行**：工具选择、单元格种类、墙状态、楼层切换（下一层 / 上一层 / 最底层 / 最高层 / 上移 / 下移）、适应窗口、格子大小、重载配置、导出 PNG。
* **画布**：合成后的迷宫，红色外框标出**当前正在编辑的楼层**。
* **状态栏**：当前楼层与各层透明百分比、鼠标所在单元（坐标 / 种类 / 四向通路）、当前工具的提示、未保存标记 `*`。

### 3.2 三种工具（工具栏「工具」下拉框）

**① 单元内容**（默认）
* 先在「单元格种类」里选：空气 / 普通地面 / 单向传送门 / 文本单元。
* **左键**：把该单元涂成所选种类。选「传送门」或「文本单元」时会弹窗让你输入目的地坐标 / 文本。
* **右键**：把该单元擦成空气。

**② 墙 / 连通**
* 先在「墙 / 连通」里选：连通（不绘制）/ 不连通（实线）/ 单向连通（虚线+箭头）。
* 鼠标要**点在两个单元的交界处附近**（离边界 28% 格宽以内），点在格子中央不会改墙。
* **左键**：设为所选状态。选「单向连通」时默认方向是「左/上单元 → 右/下单元」；
  按住 **Shift+左键** 得到反方向。
* **右键**：在 连通 → 不连通 → 单向 → 连通 之间循环，方便快速试。
* 判断点击位置用的是「离最近的那条边更近」：靠近上下边界就改上下方向的墙，靠近左右边界就改左右方向的墙。

**③ 传送门连线**
* 两次点击：先点**起点**单元，再点**目的地**单元；会自动把起点设为传送门单元。
* 点同一个格子或按 **Esc** 取消。
* 传送门箭头从起点单元中心指向目的地单元中心，颜色为 `portal_color`（默认品红），只支持同层。

### 3.3 键盘 / 鼠标快捷操作

| 操作 | 作用 |
| --- | --- |
| 中键拖动 | 平移画布 |
| 方向键 | 平移画布 |
| 滚轮 | 上下滚动 |
| Ctrl+滚轮 或 `Z` / `X` | 缩小 / 放大单元格 |
| `PageDown` / `PageUp` | 下一层 / 上一层 |
| `Home` / `End` | 最底层 / 最高层 |
| `Delete` | 清空当前楼层的所有内容与墙（会确认） |
| `Ctrl+S` / `Ctrl+Shift+S` / `Ctrl+O` / `Ctrl+N` | 保存 / 另存为 / 打开 / 新建 |
| `Esc` | 取消传送门待定起点 |

### 3.4 楼层与颜色规则

* 楼层号：地上为 `1, 2, 3, ...`（栈底是 1 层），地下为 `-1, -2, -3, ...`（栈顶是 -1 层）。
  新建迷宫时会问你「是否作为地下室编号」。不存在 0 层。
* 颜色 = `color_group[(楼层号 - 1) mod 8]`；地下楼层从色组**末尾往前**取，
  所以 -1 层 = 紫、-2 层 = 蓝、9 层 = 黑，与需求一致。
* 透明度 = `0.5 ^ |栈内下标之差|`：当前层 100% 不透明，上下 1 层 50%，2 层 25%，3 层 12.5%…
* 合成顺序：从栈底到栈顶依次 alpha 合成，所以高层覆盖低层。

## 4. 文件格式

```jsonc
{
  "format": "maze-map-designer",
  "version": 1,
  "width": 12,          // 单元列数
  "height": 9,          // 单元行数
  "basement": false,    // true = 整叠楼层按地下室编号
  "active": 0,          // 上次编辑的栈内下标
  "layers": [
    {
      "name": "",
      "cells": [ [x, y, {"kind": "text", "text": "起点"}] ],   // 只存非空气单元
      "edges": [ [cx, cy, axis, a_to_b, b_to_a] ]              // 只存非“双向连通”的边
    }
  ]
}
```

* `axis`：`0` 表示这条边分隔 `(cx, cy)` 与 `(cx+1, cy)`（左右相邻，画**竖线**）；
  `1` 表示分隔 `(cx, cy)` 与 `(cx, cy+1)`（上下相邻，画**横线**）。
* `a_to_b` / `b_to_a`：两个方向是否可通行。`[1,1]` = 连通（不画）、`[0,0]` = 实线、
  `[1,0]` / `[0,1]` = 单向（虚线 + 箭头，箭头指向可通行方向）。
* 传送门只存同层目的地：`{"kind": "portal", "portal": [x, y]}`。

## 5. 配置文件 `config.json`

```jsonc
{
  "color_group": ["#000000", "#FF0000", "#FF7F00", "#FFFF00",
                  "#00FF00", "#00FFFF", "#0000FF", "#8000FF"],
  "portal_color": "#FF00FF",
  "wall": { "width": 3, "dash": [6, 4], "arrow_length": 0.22, "arrow_width": 3 },
  "cell_size": 40,
  "text": { "font_family": "Microsoft YaHei", "min_size": 5, "fill_ratio": 0.88 }
}
```

* `color_group`：楼层色循环组，按楼层号循环取用。
* `portal_color`：传送门箭头颜色，与楼层色无关。
* `wall`：实线宽度、虚线节拍（`[实线长, 空白长]`，单位像素）、箭头长度（占格宽比例）、箭头宽度。
* `cell_size`：默认单元格像素；`text`：文本字体、最小字号、文本占格比例（自适应字号的上限）。
* 改完配置后在界面点「重载配置」即可生效，不必重启。

## 6. 源码结构

| 文件 | 作用 |
| --- | --- |
| `app.py` | Tkinter 界面：工具栏、画布、鼠标/键盘编辑、文件对话框 |
| `maze.py` | 数据模型：`Maze`（楼层栈）、`Layer`（单元 + 有向边）、`CellData`、存读 |
| `renderer.py` | Pillow 渲染：按层 alpha 合成、实线/虚线+箭头、传送门箭头、文本自适应字号 |
| `config.py` | 配置读取与默认值、色组循环规则 |
| `cli.py` | 命令行渲染 / 转换工具 |
| `tests/test_maze.py` | 数据模型、配置、渲染的像素级断言 |
| `tests/test_gui.py` | GUI 冒烟测试（模拟鼠标事件） |
